# ISS-0004 — Delete (hide) conversations from rx

GitHub: [#4 — Delete (hide) conversations from rx](https://github.com/humanitas-labs/rx/issues/4)

Some conversations should never appear in rx at all (any view, any Space). Since Messages.app remains the system of record, rx can hide them entirely at the workflow layer — never touching chat.db — and the conversation stays accessible in Messages.app.

Work:

1. Workflow store: a hidden flag (or terminal state) per conversation, surviving restart; decide whether a new inbound message un-hides (recommendation: no — hidden is explicit and sticky, unlike archive).
2. Command + keybinding + context-menu action to hide; an unhide path (probably a hidden-conversations list reachable from the palette).
3. Read models exclude hidden conversations everywhere, including search.
