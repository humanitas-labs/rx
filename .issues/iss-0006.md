# ISS-0006 — Swipe-to-reveal triage actions on sidebar rows

GitHub: [#6 — Swipe-to-reveal triage actions on sidebar rows](https://github.com/humanitas-labs/rx/issues/6)

Replace the hover snooze/archive buttons on sidebar conversation rows with a left-swipe reveal, like native iMessage: swiping a row left slides it to expose triage actions, which can then be tapped.

Actions, left to right: **snooze**, **archive**, **trash** (hide in rx — see #4). Circular buttons, colored.

## Design

Frame: [RX / Chat / Row swipe (v0)](https://www.figma.com/design/zL4rZa8PPB6rj0KBNiunE7/RX?node-id=104-74)

## Notes

- Trackpad two-finger horizontal scroll on a row is the macOS equivalent of the touch swipe; wheel/gesture events with `deltaX` drive the reveal.
- The hover buttons are removed as part of this change (interim state may ship without them — keyboard, context menu, and palette still cover the actions).
- Keep the row virtualization intact; the reveal is per-row transform state.
- Trash does not delete in Messages.app. It hides the conversation in rx (#4).
