# ISS-0019 — Blur the reader header so messages scroll underneath

GitHub: [#19 — Blur the reader header so messages scroll underneath](https://github.com/humanitas-labs/rx/issues/19)

Wanted: Messages.app-style frost — the thread scrolls the full height of the pane, and the header (avatar + name pill) sits on a blurred, mostly-transparent wash so bubbles fade out behind it rather than clipping.

Composer at the bottom can stay opaque for now. Do not change auto-scroll or paging behavior; this is a paint/layout pass on the header overlay.
