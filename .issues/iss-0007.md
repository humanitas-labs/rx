# ISS-0007 — Thicker caret in the composer text box

GitHub: [#7 — Thicker caret in the composer text box](https://github.com/humanitas-labs/rx/issues/7)

The native text caret in the composer reads too thin. CSS has no supported caret-width property (`caret-shape` is unimplemented in Chromium), so a thicker caret means hiding the native one (`caret-color: transparent`) and rendering a custom caret overlay positioned from the selection range, with blink animation and correct behavior on selection, scroll, and IME input.

Small visual win, non-trivial mechanics — bundle with other composer polish.
