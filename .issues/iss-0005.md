# ISS-0005 — Keybinding u: mark a conversation unread

GitHub: [#5 — Keybinding u: mark a conversation unread](https://github.com/humanitas-labs/rx/issues/5)

Pressing `u` on a conversation should mark it unread in rx by rewinding the rx seen watermark (the per-conversation seen message identifier in workflow.db). Purely an rx-side state change; Apple's `is_read` is never touched.

Work:

1. Workflow store: `markUnseen(chatGuid)` that rewinds or clears the watermark.
2. IPC command + `u` keybinding in sidebar and reader + palette entry.
3. Unread indicator reflects it immediately; opening the conversation while focused re-marks seen as usual.
