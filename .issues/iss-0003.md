# ISS-0003 — Rich link metacards in the reader

GitHub: [#3 — Rich link metacards in the reader](https://github.com/humanitas-labs/rx/issues/3)

Link messages currently render as a plain text bubble containing the URL. Messages.app renders a card: title, site name, and preview image. The data is already on disk — the `.pluginPayloadAttachment` alongside a `com.apple.messages.URLBalloonProvider` balloon contains an `LPLinkMetadata` keyed archive. As of f90a304 rx hides these payload internals (they used to surface as meaningless file chips).

Work:

1. Decode the keyed archive (NSKeyedArchiver binary plist; no native module expected).
2. Extract title / site / preview-image reference.
3. Render a metacard bubble in the reader; fall back to the plain URL bubble when decode fails or the payload is missing.
