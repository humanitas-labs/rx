# ISS-0011 — Contact photos instead of initials

GitHub: [#11 — Contact photos instead of initials](https://github.com/humanitas-labs/rx/issues/11)

Sidebar and reader avatars currently show initials derived from the conversation name. Wanted: the contact's photo from the system address book when one exists, initials as the fallback.

The Contacts helper today dumps name / phones / emails only. This needs an image channel that stays in memory (or a short-lived object URL) and is never written to workflow.db. Groups with no single photo keep initials or the group glyph.
