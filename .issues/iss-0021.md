# ISS-0021 — Window vibrancy so the desktop shows through

GitHub: [#21 — Window vibrancy so the desktop shows through](https://github.com/humanitas-labs/rx/issues/21)

Messages.app (and the v0 frames) let the desktop wallpaper bleed through a dark, blurred wash. rx is a solid #141414 slab in both BrowserWindow.backgroundColor and body CSS.

Wanted: macOS under-window vibrancy on the chrome — sidebar, reader gutters, header — with a dark (and later light) tint so the wallpaper reads as grain, not as a photo behind the thread. Bubbles, composer, selected rows, and overlays stay opaque.

Electron 38 already has the hook (`vibrancy: 'under-window'`, transparent window background, rgba wash instead of hex). This is NSVisualEffectView, not Tahoe liquid glass.

Related: #19 (header frost over the thread) is a different layer — messages under the avatar, not the desktop under the window.
