# ISS-0016 — Keyboard: gg/G, h/l pane focus, and jk as Escape

GitHub: [#16 — Keyboard: gg/G, h/l pane focus, and jk as Escape](https://github.com/humanitas-labs/rx/issues/16)

Navigation additions, to be written into `docs/spec/keyboard.md` before implementation.

**List extremes (`gg` / `G`)** — in Navigation mode on the conversation list, `gg` selects the first row and `G` the last. Same selection+open behavior as `j`/`k`. Chord window matches `g s` (750 ms). `G` is a single key (shift-g), not a chord.

**Pane focus (`h` / `l`)** — `l` moves focus from the list into the open conversation (reader / ready for `i`). `h` returns focus to the list without closing the conversation. Escape still works; `h`/`l` are the preferred hop so Escape is not the only way out of the reader. Insert mode is unchanged: Escape (or `jk` below) is still the exit.

**`jk` as Escape** — Andrew's default Vim mapping. In Insert (and Filter) mode, `j` then `k` in a short window leaves the field the same way Escape does: draft preserved, back to Navigation. A lone `j` that is not followed by `k` inserts `j`. Navigation-mode `j`/`k` are unchanged (they already mean next/previous conversation).
