# ISS-0013 — Group the snoozed list by wake time

GitHub: [#13 — Group the snoozed list by wake time](https://github.com/humanitas-labs/rx/issues/13)

Snoozed is currently a flat list ordered soonest-wake-first. Wanted: visual time groups by wake time (today / tomorrow / later this week / later), similar to how the reader already separates message history by time.

Ordering inside a group stays soonest wake first. Group headers are display-only; they are not extra selectable rows for `j`/`k`.
